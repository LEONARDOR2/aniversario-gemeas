# Aniversário em dose dupla

Página estática para celular, feita com HTML, CSS e JavaScript. Abra `index.html` no navegador para usar. Não precisa instalar dependências. As fontes do Google são opcionais: sem internet, a página usa as fontes do sistema.

## Personalizar

- Em `script.js`, altere `name` e `message` das duas irmãs.
- Em `index.html`, altere a mensagem conjunta e a assinatura.
- As mensagens atuais são exemplos. A foto conjunta está em `images/momento-juntos.jpeg`.

## Publicar no GitHub Pages

Envie `index.html`, `style.css`, `script.js` e a pasta `images` para um repositório do GitHub. Em **Settings → Pages**, selecione **Deploy from a branch**, a branch com os arquivos e a pasta **/ (root)**. Depois de concluir a publicação, o GitHub mostrará o endereço do site.

Não coloque fotos ou informações privadas em um repositório público. Este projeto ainda não foi publicado.
